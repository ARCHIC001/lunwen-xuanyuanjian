# ⚔️ 论文轩辕剑

### 一剑开天地，五式定乾坤——论文 Introduction 神话级终极大法

传说远古学术江湖中，有一柄神剑，专斩引言混沌：斩散漫背景，破文献罗列，贯通研究缺口，直抵贡献之巅。**论文轩辕剑**便是这柄为科研写作者锻造的 AI Agent Skill。

当你的 Introduction 陷入「讲了很多，却不知为何而战」的迷雾，召唤此剑，让问题、方法与证据汇成一条清晰的叙事长河。

## 轩辕五式

1. **开天辟地**：交代研究世界与真正值得关注的问题。
2. **破阵寻隙**：梳理代表性路线，找出共同且关键的局限。
3. **神剑出鞘**：以一句清晰的方法主张回应缺口。
4. **剑意通玄**：解释核心机制如何针对问题发挥作用。
5. **功成铭碑**：以可检验的贡献收束全文，呈现研究价值。

神话归神话，落笔须有凭据：这套方法强调区分设想与实证，控制结论范围，让叙事张力建立在真实研究之上。适用于机器学习、人工智能及相关技术领域的 Introduction 构思、诊断与改写。

## 安装与召唤

将仓库克隆到 Codex skills 目录：

```sh
git clone https://github.com/ARCHIC001/lunwen-xuanyuanjian.git ~/.codex/skills/introduction-story-arc
```

如有需要，重启 Codex，然后在对话中召唤：

```text
$introduction-story-arc 帮我诊断这篇论文的 Introduction，并重新组织研究缺口和贡献叙事。
```

建议提供摘要、方法、实验结果、参考文献、目标会议及现有引言。此 skill 辅助组织论证，不能代替文献调研或实证核查。
